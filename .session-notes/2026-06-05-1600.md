## Root cause identified: dioxus.send() requirement

Critical Dioxus API insight discovered across Bugs 2 and 6: `document::eval().await`
blocks until JavaScript calls `dioxus.send(value)`. A bare `return value`, a resolved
`Promise`, or a `setTimeout` callback that calls `resolve()` do NOT unblock the Rust
`await`. Every eval that needs to resolve must end with `dioxus.send(...)`.
